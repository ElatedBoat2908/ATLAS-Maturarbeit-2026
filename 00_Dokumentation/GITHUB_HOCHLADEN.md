# GitHub-Einrichtung – Schritt für Schritt

1. Auf GitHub ein neues Repository erstellen (z. B. `ATLAS-Maturaarbeit-2026`), zunächst **Private**.
2. Dieses ZIP **entpacken**. In GitHub **Add file → Upload files** die Ordner `00_Dokumentation`, `B1_...` bis `B7_...` und die Dateien `README.md`, `DATEIMANIFEST_SHA256.csv`, `pruefe_dateien.py` hochladen. Nicht das ZIP als einzige Datei hochladen.
3. Repository prüfen: Die README sollte auf der Startseite lesbar sein; die Python-Dateien in B2 sollten sich im Browser öffnen lassen.
4. Die Aufgaben aus `VOR_VERÖFFENTLICHUNG.md` erledigen. Den unterschriebenen Projektvertrag niemals in das öffentliche Repository hochladen.
5. Erst danach in den GitHub-Repository-Einstellungen zu **Public** wechseln und einen Release-Tag (z. B. `v1.0-maturaarbeit`) anlegen.
6. URL zum konkreten Release in den digitalen Anhang deiner Maturaarbeit einfügen und einen anklickbaren Link im PDF testen; optional QR-Code ergänzen.
